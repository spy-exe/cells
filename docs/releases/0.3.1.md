# Cells 0.3.1 — organic movement and compatible expedition foundation

The client now renders small, seeded contour waves on a 96-point vector membrane.
The area is normalized; collision physics remains circular and server-owned.
Reduced-motion preference disables contour/deformation and absorption travel.
Food disappearing next to an existing growing visible cell animates into its body
for 170ms. This is bounded visual inference, not an authoritative eat event.

Names always follow the body center, adapt to screen radius, abbreviate when
needed and disappear only below legibility size. Bodies and labels share ascending
mass order, so a smaller cell cannot visually cover a larger predator. Viruses
retain 48 tips and lose their dark outline. Mouse targeting now uses the actual
rendered camera and near-cursor speed falls off to stop smoothly.

Public Classic carries 24 mixed tactical agents; AI Arena 32 agents of the selected
profile. Private Classic remains human-only. Older room checkpoints backfill the
population without duplicating bots or replacing the selected policy. Tactical
work is spread uniformly across six ticks, retaining five decisions/second per
agent instead of making the whole population think on one tick. A regression
checks the actual observation-memory updates for all32 agents over12 ticks.

Expedição code/UI/state contracts are included, with new production entries
initially OFF. See [rules and compatibility](../game-design/expedition.md). This
release is the application rollback baseline before enabling the mode in0.4.0.
