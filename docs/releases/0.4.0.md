# Cells 0.4.0 — Expedição

Expedição is a playable experimental solo mode, composed over the authoritative
Classic physics. It offers three25-second sectors, mass targets60/100/160, two
mutation choices, expanding tactical waves and a final Sentinela. It has victory,
consumption and insufficient-mass outcomes. Each attempt gets a fresh seeded map.
Classic and AI Arena receive no mutations or cross-mode advantages.

[Cílios, Metabolismo and Coesão rules](../game-design/expedition.md) affect actual
speed, food intake or merge cooldown. Choices pause the simulation and require an
eligible server phase/revision. Save/reload preserves the seed, phase, deadlines,
mutations, statistics and bot memories. R or the result button starts a fresh run,
resetting progression while retaining the session's mass record.

The production rollout first establishes0.3.1 with new entries disabled, then
sets `CELLS_EXPEDITION=1` only on the isolated Cells service. Existing saves remain
readable when the flag is disabled. Rollback must use0.3.1 or newer after the first
Expedição save; older application binaries do not understand the Rogue mode.
No destructive database migration or shared proxy/DNS change is involved.

## Evidence boundaries

- Native deterministic state-machine tests cover all phases and duplicate/stale
  choices. Full engine tests verify each actual mutation effect and mass ledger.
- Real32-agent memory updates prove the5Hz tactical schedule spreads work across
  six ticks. [Measured load](../performance/0.3.1-load.json) covers the shared
  simulation at100 human connections and224 tactical bots, not WAN capacity.
- Four native full-physics seeds, without mass grants or time jumps, produced
  three reference-agent victories and one early death. This establishes a tested
  possible path, not a human success-rate or difficulty estimate.
- Browser real-game tests cover solo entry, movement and seed-preserving reload.
  Choice/result fixtures explicitly test layout, accessibility and controls;
  native tests prove their actual authoritative consequences.
- The existing CPU PPO model failed its earlier held-out evaluation and remains
  outside production. All displayed bots, including Sentinela, are programmed
  visible-information utility policies, not newly trained models.

Exact commits, CI results, public screenshots, authenticated checkpoint proof,
backup restore and public smoke logs are attached to the GitHub release after
those operations complete. This report does not assert an unperformed deploy.
